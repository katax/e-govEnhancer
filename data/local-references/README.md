# 同梱法令を引用元とする逆リンク

`references.json` は同梱カタログ105件（規則類104件・告示1件）の本文を調べて生成した逆リンク索引です。対象法令ID → 対象条項キー → `externalLawSources` の構造と、各引用元の `sourceLawId` / `sourceLawTitle` / `sourceUrl` は従来の全法令版と同じです。本文のない法令を引用元とする行は含みません。

同一法令内の参照は既存の本文解析と重複するため含めません。参照先には通常の法令と他の同梱規則の両方を含みます。「不公正な取引方法」から独占禁止法への参照も収録しています。各引用元は同じ参照先・同じ出典箇所につき1件です。

## 引用元URLと利用時の注意

引用元IDは `catalog.json` にある同梱IDです。`sourceUrl` は `viewer.html?localRule=<slug>#<DOMの箇所ID>` という拡張機能内の相対URLです。Chromeの拡張機能IDを固定せず配布できます。利用時は `chrome.runtime.getURL(source.sourceUrl)` で絶対URLへ変換してください。通常ページのURLを基準に解決したり、同梱IDをe-Govの法令IDとしてAPIへ送らないようにします。

通常・Lite共通のバックグラウンド処理で `index.json` の対象IDを判定し、一致する場合だけ本JSONを読み込んでAPI結果へ合流します。APIの保存キャッシュ自体は変更せず、取得済みのAPI結果にも最新版の同梱索引を合流します。

同梱引用元には青い「ローカル」タグを表示します。ポップアップ設定では同梱ビューアをページ内に埋め込み、全文を表示しつつ引用元の条文へ移動します。タブで開く設定とCtrlによる一時的な開き方の切り替えにも従います。

全法令版と256分割JSONは作業ツリーから削除しました。削除前の258ファイルを `tmp/full-references-backup-20261101/full-references.zip` に退避し、全エントリのSHA-256一致を検証しています。`tmp/full-references-backup-20261101/restore.ps1` でデータを復元できます。配布物には本JSONとID一覧のみを入れ、確認記録・法令名辞書は含めません。

## 再生成と検証

ChromeとPlaywrightが利用できる環境で、プロジェクトルートから実行します。

```
node tools/build-local-references.cjs
node tools/validate-local-references.cjs
```

生成時は外部への通信を行いません。既存の同梱ビューアをローカルのブラウザで動かして参照を抽出し、現在の全法令版から得た法令名・ID辞書で照合範囲を補います。その辞書は `law-names.json` に保存し、全法令版を除去した後も再生成できます。XMLや法令名辞書の変更時は再生成してください。

## 抽出範囲と確認用記録

`build-report.json` に105件それぞれの処理件数・入力ハッシュ・抽出根拠・確認対象を記録しています。条項の範囲指定は解決可能な連続する条について展開しています。

既存の条文リンク生成規則を利用しているため、略称や文脈依存の参照、旧法・新法、複雑な範囲指定などの完全な解決を保証するものではありません。リンクにならなかった明示的な引用らしきテキストを `review` に記録しています。これは候補の数であり、未収録の参照件数とは一致しません。確認対象を推測で逆リンクに追加していません。

同梱版の本文に基づく索引であり、過去・未来の法令版に対して当該時点の引用関係を証明するデータではありません。
