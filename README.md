# e-Gov法令検索 Enhancer

この拡張機能は、`https://laws.e-gov.go.jp/` 向けの Chrome 拡張機能です。

`Chrome` や `Microsoft Edge` では、ストアに公開していない拡張機能でも「パッケージ化されていない拡張機能」として読み込めます。ここでは、この GitHub リポジトリから ZIP をダウンロードしてインストールする手順を説明します。

## インストール手順

1. 右上付近の `Code` ボタンを押して、`Download ZIP` を選びます。

2. ダウンロードしたZIPファイルを展開します。（ZIPファイルを右クリックして「すべて展開」を選ぶ）

3. ブラウザで拡張機能管理画面を開きます。
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`

4. 右上の「デベロッパー モード」を `ON` にします。

5. 「パッケージ化されていない拡張機能を読み込む」をクリックします。

6. ZIPを展開してできたフォルダのうち、`manifest.json` が入っているフォルダを選択します。（変更していなければe-pubEnhancer-mainというフォルダ名のフォルダのはずです）

7. 一覧に `e-Gov法令検索 Enhancer` が表示されたらインストール完了です。

## 使い方

- Chrome上のどこからでも、Ctrl+Shift+eでe-Gov法令検索を起動できます。
   - 左キーで開いた法令の履歴のリスト、右キーでお気に入りのリストにアクセスできます。お気に入りは★をクリックするか、Shift+Enterで登録/解除ができます
- 法令画面ではsキーを押すとページ内検索ダイアログを、数字キーで条文ジャンプダイアログを起動できます。その他の機能は？キーを押すと開くガイドをご参照ください。


## 更新方法

GitHubから新しいZIPをダウンロードして展開し直したあと、拡張機能管理画面でこの拡張機能の `再読み込み` を押してください。

## 通常画面の読み込み高速化

一度開いた法令の本文・目次・改正情報をブラウザー内に保存し、次回の表示で再利用します。画面と各機能の使い方は同じです。拡張機能を更新した場合は、拡張機能と法令ページを再読み込みすると有効になります。

通常表示では、法令名の下の「未施行あり」の隣に、表示中の版を示す「現行版」「過去版」（将来の版は「未施行版」）を同じ体裁で表示します。「未施行あり」がない法令でも表示します。判定には読み込んだ改正履歴を使い、判定できない場合は表示しません。

e-Gov所定のフッタ内に「法令ファイル取得日時」と追加ボタンを配置します。日時は左寄せで、キャッシュを開き直しても更新しません。「法令ファイルの再取得」「Lite」「マニュアル」「オプション」「ヘルプ」は独立したボタンで並び、標準の「印刷」「ダウンロード」もそのまま使えます。「法令ファイルの再取得」を押すと、その法令をキャッシュを使わずに取得し直します。

現行版として開いた法令は、表示完了後に最新の施行済みの版と比較します。異なる場合は「法令ファイルの再取得」ボタンが濃いオレンジになり、マウスを重ねると「法令に更新があります」と表示します。本文を勝手に差し替えることはありません。過去の時点・版を指定した表示と同梱のローカル規則は対象外です。未施行の改正しかない場合や、通信に失敗して確認できなかった場合は更新通知を出しません。

フッタの「Lite」でLiteモードを開き、「ヘルプ」でショートカット一覧を表示します。ヘッダには切替ボタンを集約し、「ショートカット」ボタンはAlt+Pとも連動します。有効時は青、無効時は他の切替ボタンと同じ淡い青で表示します。ヘッダ・フッタのボタンにマウスを重ねると説明が表示され、ショートカットがある場合は「ショートカットを有効化（ALT+P）」のようにキーも併記します。ヘルプは再クリック・「閉じる」・Esc・外側のクリックで閉じられます。

オプション画面の「法令の自動再ダウンロード（通常・Lite共通）」で、「毎回（キャッシュを利用しない）」「毎日」「毎週」「毎月」「なし（手動のみ）」を選べます。初期値は「毎日」です。法令を開くとき、前回のダウンロードから1日・7日・30日が経過していれば取り直します。ブラウザーを閉じている間や、開いていない法令を定期的に取得する機能ではありません。「毎回」ではローカルキャッシュを読み書きせず、「なし」では保存済みデータを期限で更新しません。表示後の更新確認では本文ではなく改正履歴だけを取得します。すぐに改正・訂正を反映したい場合は「法令ファイルの再取得」を押してください。保存されていない法令は、どの設定でも取得します。

保存容量はオプション画面の「法令のローカル保存容量（通常・Lite共通）」で1〜4096MiBの範囲で指定できます。初期値は256MiBです。新しいデータの保存前に容量を確認し、上限を超える分を最終アクセスが古い順に削除します。容量を減らした場合も次の保存時に適用します。1応答8MiBまたは指定容量より大きい応答は保存せず表示します。通常モードとLiteモードの合計で容量を管理します。Lite画面も同じ頻度で更新し、法令ファイル取得日時と手動の再取得に対応します。

## 注意

- ブラウザをまたいで使う場合は、それぞれのブラウザで読み込みが必要です。

メモ・ハイライトの復元では、保存時から文字位置がずれた場合に元の条・項の中で同じ文言を探し直します。本文が変わった場合や候補が複数ある場合は、自動で別の箇所に移しません。復元できない通知では「テキスト保存」「削除」「無視」を選べます。保存領域の一時的な読み込み失敗は最大3回自動で再試行し、失敗時に保存データを消すことはありません。

## お気に入り・メモの保存と読み込み

データはブラウザー内に保存します。オプション画面の「保存」でJSONを書き出し、「読み込み」で取り込めます。外部ファイルへの自動保存・同期は終了しました。すでに保存したJSONは引き続き利用できます。

読み込み方法は「マージ」（初期値）と「置き換え」から選べます。

- マージ：ファイルにない現在のデータも残します。お気に入りは法令IDで重複を除き、現在の登録内容を優先します。同名のフォルダーはまとめ、フォルダーIDだけが衝突する場合は区別して取り込みます。メモは法令とメモIDで照合し、更新日時の新しい内容を採用します。同時刻なら現在の内容を残します。
- 置き換え：現在の対象データをファイルの内容に入れ替えます。ファイルにない現在のデータは削除します。

お気に入りの上限50件、ハイライトの上限は1法令10,000件です。マージ後に上限を超える場合は読み込みを中止し、現在のデータを保持します。読み込み前には選択した方法とファイルの件数を確認できます。
