# e-Gov法令検索 Enhancer

この拡張機能は、`https://laws.e-gov.go.jp/` 向けの Chrome 拡張機能です。

`Chrome` や `Microsoft Edge` では、ストアに公開していない拡張機能でも「パッケージ化されていない拡張機能」として読み込めます。ここでは、この GitHub リポジトリから ZIP をダウンロードしてインストールする手順を説明します。

## インストール手順

1. 右上付近の `Code` ボタンを押して、`Download ZIP` を選びます。

2. ダウンロードしたZIPファイルを展開します。（ZIPファイルを右クリックして「すべて展開」を選ぶ）

3. ブラウザで拡張機能管理画面を開きます。
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`

4. 右上の「デベロッパー モード」を `ON` にします。

5. 「パッケージ化されていない拡張機能を読み込む」をクリックします。

6. ZIPを展開してできたフォルダのうち、`manifest.json` が入っているフォルダを選択します。（変更していなければe-pubEnhancer-mainというフォルダ名のフォルダのはずです）

7. 一覧に `e-Gov法令検索 Enhancer` が表示されたらインストール完了です。

## 使い方

- Chrome上のどこからでも、Ctrl+Shift+eでe-Gov法令検索を起動できます。
   - 左キーで開いた法令の履歴のリスト、右キーでお気に入りのリストにアクセスできます。お気に入りは★をクリックするか、Shift+Enterで登録/解除ができます
- 法令画面ではsキーを押すとページ内検索ダイアログを、数字キーで条文ジャンプダイアログを起動できます。その他の機能は？キーを押すと開くガイドをご参照ください。


## 更新方法

GitHubから新しいZIPをダウンロードして展開し直したあと、拡張機能管理画面でこの拡張機能の `再読み込み` を押してください。

## オプション画面の開き方

拡張機能管理画面のこの拡張機能カードから `詳細` を開き、`拡張機能のオプション` を開いてください。

## 外部ファイルによる任意の同期

設定画面の「お気に入りの保存と読み込み」「メモとハイライトの保存と読み込み」にある「外部ファイルで自動保存・同期（任意）」から、それぞれ個別に設定できます。未設定時は従来どおりブラウザー内だけに保存します。

1. 最初の端末で「現在の内容で新規ファイルを作成」を押し、Google Drive や OneDrive の同期フォルダーに JSON ファイルを作成します。
2. 他の端末では、同期されたファイルを「既存ファイルを指定」で選びます。このとき端末内の対象データをファイルの内容で置き換えます。
3. 変更は自動保存されます。ブラウザー起動中は約30秒ごとにファイルの変更を確認して読み込みます。「今すぐ更新を確認」も利用できます。ファイル自体の転送には各同期サービスのデスクトップアプリが必要です。ファイルは端末上で読み書き可能な状態にしてください。

メモは位置情報のあるハイライトと一緒に保存します。お気に入り側にはフォルダー・折りたたみ状態を含みます（条文ブックマークは対象外）。既存の JSON エクスポート形式と互換です。外部ファイルを使っていても端末内のコピーを保持します。

ファイルの削除・移動、空ファイル、不正な JSON、アクセス権の喪失時は、端末内のデータを削除せず読み書きを保留します。読み取れるようになれば再確認します。空のデータへの変更や両側で変更された競合は自動上書きを止めるため、設定画面で採用する内容を選んでください。ファイル消失後も端末内で編集を続けられ、「現在の内容で新規ファイルを作成」で新しい保存先へ復旧できます。

取り込みや上書き前のバックアップはカテゴリごとに直近3件を端末内に保持します。「競合の解決・データの保全」から JSON で保存し、既存のインポート機能で戻せます。利用解除ではファイルも端末内のデータも削除しません。ブラウザー再起動後に権限が失われた場合は「アクセスを再許可」を押してください。

クラウド側で同時に変更された場合の完全な排他制御はできないため、別端末で編集する前に同期完了を待って更新を確認してください。ブラウザー終了中・スリープ中は取り込まず、再開後に確認します。
