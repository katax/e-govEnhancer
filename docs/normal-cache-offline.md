# 通常キャッシュからの接続失敗時表示

通常モードで法令を開く際に通信エラーとなった場合、`/concentration` に遷移した場合、本文の取得に失敗した場合は、同じタブで拡張機能のLite表示へ切り替えます。本文の取得元は通常モードの `egov-normal-responses-v1` キャッシュだけです。LiteのXMLキャッシュやe-Govへの追加通信を必要としません。

画面上部に次の文を常時表示します。

> e-Gov法令検索にアクセスできなかったため、キャッシュを利用してLiteモードで表示しています

取得日時は下部に表示し、「e-Govで再接続」から元のURLへ戻れます。自動的な逆リンク取得・改正確認・比較表示は行いません。保存済みの表示であることを明示し、更新期限を過ぎたキャッシュも緊急時には読み出します。

## 保存データの識別

通常キャッシュ保存時に、法令ID・表示URL・本文形式・改正版IDをレスポンスヘッダーへ記録します。URLのハッシュと表示タブは本文の同一性に影響しませんが、過去時点や改正版指定は区別します。ハッシュ検証に失敗した保存データや、別法令・別時点の本文は利用しません。キャッシュの複製は作らず、従来の法令キャッシュ容量上限を使用します。

以前のキャッシュには検索に必要な識別情報がないため、この変更後に通常モードで一度オンライン表示すると、既存のキャッシュヒット時にも識別情報を付けます。保存日時は更新しません。識別情報のないキャッシュから法令や時点を推測して表示することはありません。

保存済み本文がない場合や、キャッシュの識別ができない場合は切り替えません。e-Govへ直接アクセスしたURLが混雑ページのみで、元の法令URLを検知できない場合も対象外です。法令への移動から10分以内のエラー・混雑ページ遷移を対象にし、移動のキャンセルや他サイトへ移動したタブは置き換えません。

## 表示形式

構造化JSON形式は法令XMLへ変換してLiteの描画処理で表示します。HTML形式は本文を保持したまま実行コード・外部読み込み等を除去し、Liteの表示領域へ配置します。本文中の目次は除きます。別途ダウンロードが必要な画像や添付ファイルまではオフライン表示を保証しません。

通常版のHTMLを表示する場合、文字サイズなどの見た目はLiteに合わせますが、構造が異なるためLiteの全編集機能と同等になるわけではありません。オフライン表示は保存済み本文を読むための画面です。

読み込み失敗とサーバーによる混雑ページへの転送を検知するため、`webNavigation` 権限を追加しています。

## 検証

- 接続失敗と混雑ページ遷移で対象タブだけを切り替えること、移動キャンセル・キャッシュ不一致・破損時は切り替えないことを検証。
- 旧キャッシュを通常モードで読むと識別情報が付与され、保存日時が維持されることを検証。
- 実通信の記録にある民法HTML・行政手続法JSONを通常キャッシュだけに保存したChromeで、Liteキャッシュなし・外部通信なしで本文と案内を表示できることを検証。
